# Weather App

A simple web application that uses [Open-Meteo's Free Weather API](https://open-meteo.com/).

## Learning Objectives

- Consume RESTful APIs to fetch real-time weather data
- Implement asynchronous JavaScript with async/await
- Design a responsive UI with modern CSS techniques

## Getting Started

Install dependencies and start the dev server:

```bash
pnpm install
pnpm dev
```
